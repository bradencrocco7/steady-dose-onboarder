# Steady Dose Onboarder

An AI onboarder for a new tutor's first day at Steady Dose Tutoring, a small business that tutors new pharmacy graduates for their licensing exam (the NAPLEX). Steady Dose is made up, modeled on the tutoring business I run.

## Who it's for

A newly licensed pharmacist starting as a part-time tutor. You play them.

## How to start

1. Click the green **Code** button above, then **Download ZIP**. Unzip it.
2. In Claude or ChatGPT, make a new **Project**.
   - **Instructions:** open `identity.md`, copy all of it, and paste it into the project's instructions. Do the same with `rules.md`, below it.
   - **Files:** add `examples.md` and every file in the `reference` folder.

   (Using Claude Code or Codex? Just open the folder.)
3. Start a chat in the project and type: **Hi, it's my first day.**

## What to ask first

- "What do I do first today?"
- "Who do I ask about pay?"
- "What if a student is 15 minutes late?" It isn't in the notes, so it should say so and tell you who to ask.

Built with ICM (Interpretable Context Methodology) by Jake Van Clief and David McDermott.
